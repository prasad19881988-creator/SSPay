# SSPay — SS Enterprises

Premium mobile-first fintech UI prototype.

## Run
1. Install Node.js
2. `npm install`
3. `npm run dev`

## Current prototype
- SS Enterprises / SSPay branding
- Premium dark fintech interface
- Home dashboard
- Scan & Pay entry
- Send / Receive / Bank Transfer UI
- Services
- Offers & Rewards
- SSPay Card UI
- Transactions
- Profile / security sections

## Important
This is a frontend prototype. Real UPI, bank transfer, KYC, ATM/debit-card issuance and live offers require approved banking/payment/card integrations and backend security.

## Branding
The uploaded SS Enterprises logo is included at `src/assets/ss-enterprises-logo.png` and is used in the app header and SSPay Card UI.
